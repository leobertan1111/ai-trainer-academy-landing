Prompt, rubrica, anotação e feedback: um glossário para começar em IA

Entenda os termos usados em tarefas de IA com um exercício autoral que separa entrada, resposta, critérios, rótulos e feedback.

Equipe AI Trainer Academy · 2026-10-31 · 3 min de leitura

Prompt é a entrada que orienta o modelo; resposta é a saída produzida; rubrica é o conjunto de critérios usado para avaliar essa saída. Anotação e feedback são registros sobre o material analisado. Entender essa sequência ajuda a ler uma tarefa sem confundir o pedido do usuário com as instruções destinadas ao avaliador.

Este glossário traduz conceitos para a prática de quem está começando. Os nomes e campos podem mudar entre projetos: use as definições da instrução recebida quando houver uma convenção própria.

Prompt e resposta: o que entra e o que sai

No glossário do Google, prompt é uma entrada textual que condiciona o comportamento de um modelo de linguagem. A resposta é o conteúdo que o sistema produz. Em tarefas multimodais, a entrada também pode envolver outros tipos de material.

Exemplo autoral: o prompt diz “Escreva um aviso de reunião em duas frases, incluindo terça-feira e 14h”. A resposta inventada é “Nossa reunião será na terça-feira. Nos vemos na sala principal!”. O aviso soa natural, mas deixou de informar o horário. Separar os dois textos permite localizar a exigência e conferir o resultado.

Rubrica: o que será observado

Uma rubrica organiza critérios e, quando aplicável, níveis de avaliação. Neste exercício, podemos definir três verificações: mencionar o dia, mencionar o horário e usar duas frases. Essa lista é nossa proposta didática, não uma rubrica de empresa.

As orientações de avaliação da OpenAI recomendam critérios ligados à tarefa e avaliações claras. Para o participante, a aplicação prática é ler o critério antes de julgar a resposta. Se o projeto pedir uma avaliação de completude, não troque esse objetivo por uma preferência sobre estilo.

Anotação, rótulo e justificativa

Neste guia, chamamos de anotação o registro estruturado feito sobre um item. Um rótulo é uma categoria atribuída, como “horário ausente”. A justificativa explica a evidência: “A resposta menciona terça-feira, mas não contém 14h”. São usos didáticos dos termos; o projeto pode empregar outros nomes.

Compare “ruim” com “horário ausente”. O primeiro registro não esclarece qual aspecto falhou. O segundo identifica o problema, mas ainda pode precisar de uma explicação textual. Preencha somente os campos pedidos e respeite o formato definido, inclusive quando não houver espaço para uma justificativa longa.

Feedback humano e RLHF

Feedback humano é a contribuição de pessoas sobre as saídas de um sistema. RLHF significa aprendizado por reforço com feedback humano: uma abordagem que usa esse feedback para melhorar respostas. Não é sinônimo de qualquer trabalho relacionado a dados ou IA.

Classificar um texto, coletar uma gravação e comparar duas respostas são atividades diferentes. O nome comercial de uma tarefa não permite concluir sozinho qual técnica de treinamento será usada depois. Para organizar sua preparação, identifique primeiro o que você precisa entregar.

Um exercício para fixar os termos

  1. Escreva o prompt do aviso em uma coluna.
  2. Coloque a resposta inventada em outra, sem alterá-la.
  3. Liste os três critérios e marque quais foram atendidos.
  4. Registre o rótulo “horário ausente” para o problema encontrado.
  5. Justifique com a comparação entre o pedido e a resposta.

A resposta atende ao dia e ao número de frases, mas falha no horário. Isso não determina uma nota universal: falta uma regra que diga como combinar os critérios. O exercício treina vocabulário e leitura, sem reproduzir qualificações reais.
